¿Cuál partido gana el próximo escaño? (Ranking de probabilidad)
¿Cómo funciona esto?
Los escaños se distribuyen usando el sistema D'Hondt. Este ranking muestra cuál partido del bloque centro-izquierda tiene más probabilidades de conseguir el siguiente escaño. Los números indican cuántos votos nuevos necesitaría cada partido para alcanzar ese escaño.
